# Lantern Pier

## Premise

A storm is two hours out and the lighthouse on Lantern Pier is dark. The player arrives on the last ferry and is the only one Mara will let help: find lamp oil, carry it up the tower, and light the lamp before the boats come home.

## Acts

### Act 1: The dark tower
- goal: Talk to Mara and learn the lamp needs oil.

### Act 2: The oil run
- goal: Find the oil can on the pier, with or without Pip's help.

### Act 3: Light the lamp
- goal: Bring the oil to Mara and light the lamp before the storm hits.

## Flags

- oil_found: set by game code when the player picks up the oil can on the pier
- lamp_lit: set by game code when the player pulls the lamp lever at the top of the tower
