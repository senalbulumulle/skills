# roblox

Roblox experiences in Luau with Rojo: design for how Roblox is played, secure server-authoritative scripting, gameplay systems, story and dialogue, and pre-publish testing.

Typical order: `roblox-game-design` → `roblox-scripting` → `roblox-gameplay`, `roblox-narrative` → `roblox-playtest`.

Install just this category: `tools/skills.py install -c roblox`
