# game-dev

Engine-agnostic game development: concept, prototype, feel, art, audio, AI, levels, procedural generation, balance, and playtesting. Defaults to HTML5 canvas and adapts to Godot, Unity, Phaser, or the engine already in the project.

Typical order: `game-concept` → `game-prototype` → `game-feel`, `game-art`, `game-audio`, `game-ai`, `game-level-design`, `game-procgen`, `game-balance` as needed → `game-playtest`.

Install just this category: `tools/skills.py install -c game-dev`
