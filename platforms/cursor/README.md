# Cursor

- Installs to: `~/.cursor/skills/` (user), `.cursor/skills/` (project)
- Invoke: automatically from `description`, or `/skill-name`
- Extra frontmatter: `paths` (globs; legacy `globs`), `disable-model-invocation`, `icon`, `color`
- Note: Cursor also reads `.agents/`, `.claude/`, and `.codex/` skill folders, so skills installed for Claude Code or Codex show up here too.
- Docs: https://cursor.com/docs/skills
