# GitHub Copilot

- Installs to: `~/.copilot/skills/` (user), `.github/skills/` (project)
- Invoke: automatically from `description`
- Extra frontmatter: none (`license` and `allowed-tools` are portable keys)
- Note: Copilot also reads `~/.agents/skills/`, and `.claude/skills/` and `.agents/skills/` in projects.
- Docs: https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/create-skills
