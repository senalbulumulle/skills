# OpenCode

- Installs to: `~/.config/opencode/skills/` (user), `.opencode/skills/` (project)
- Invoke: automatically from `description`
- Extra frontmatter: `disable-model-invocation`
- Note: OpenCode also reads `.claude/skills/` and `.agents/skills/` (user and project).
- Docs: https://opencode.ai/docs/skills
