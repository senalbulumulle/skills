# Gemini CLI

- Installs to: `~/.gemini/skills/` (user), `.gemini/skills/` (project)
- Invoke: automatically from `description` (Gemini asks before activating), list with `/skills`
- Extra frontmatter: none
- Note: Gemini also reads `.agents/skills/`, and that folder wins over `.gemini/skills/` when names collide. If you install a Gemini variant, don't install the same skill for Codex at the same level.
- Docs: https://geminicli.com/docs/cli/skills/
