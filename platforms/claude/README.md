# Claude Code

- Installs to: `~/.claude/skills/` (user), `.claude/skills/` (project)
- Invoke: automatically from `description`, or `/skill-name`
- Extra frontmatter: `when_to_use`, `argument-hint`, `arguments`, `disable-model-invocation`, `user-invocable`, `disallowed-tools`, `model`, `effort`, `context`, `agent`, `background`, `hooks`, `paths`, `shell`
- Note: claude.ai uploads accept only the portable keys, so keep Claude-only keys in this folder.
- Docs: https://code.claude.com/docs/en/skills
- MCP servers: see `mcp/` (for example `mcp/web-dev/motion-forge/README.md` for Claude Code setup).
