# Hybrid LLMS (Hybrid Local Language Model Server)

Hybrid Local Language Model Server is a server daemon for running local language models (qwen)
with the combination of cloud models such as Claude, Codex, and Gemini. 


The purpose of this solution allows the ability to both Local and Cloud Models to communicate
each other and work together, which has a complete benefit of saving cloud tokens, more effort
communication of the prompts, and more to experiment.
