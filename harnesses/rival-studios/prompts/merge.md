## Rules

1. Work only in the current folder. The rival folders are for reading: never change them.
2. Read how each idea works in its rival build, then rebuild it to fit your code, look, and names. Don't paste their code over yours.
3. Keep what made your build win. If an idea would break it, skip that idea and say why.
4. Run or build it again and fix every error. Add a line to `RIVAL.md` for each idea you took.
5. Don't publish, deploy, or push anything.
