## Rules

1. Work only in the current folder. It is a git worktree on its own branch; don't switch branches or touch other folders.
2. Read what already exists first, and use the skills you have for this kind of work (for a game: concept, prototype, feel, playtest).
3. Get the smallest working version running early, then improve it. A finished small thing beats an unfinished big one.
4. Use real names, numbers, and text that fit the idea, never placeholders.
5. Before you finish, run or build it and fix every error you see. Leave a short `RIVAL.md` at the root: how to run it, and the one thing that makes this version special.
6. Don't publish, deploy, or push anything.
